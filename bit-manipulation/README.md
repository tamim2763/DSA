# Bit Manipulation

Small snippets demonstrating bitwise operations and common bit tricks.

Files:

- `get_ith_bit.cpp` — check if i-th bit is set
- `set_ith_bit.cpp` — set/clear/unset i-th bit
- `update_ith_bit.cpp` — update i-th bit to 0 or 1
- `clearLastIbits.cpp` — clear last i bits
- `clearRangeOfBits.cpp` — clear a range of bits
- `complement.cpp` — demonstrate bitwise complement
- `insert_m_to_n.cpp` — insert bits from m into n between i..j
- `left_right_shift.cpp` — left & right shift examples
