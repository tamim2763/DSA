# Sorting

This folder contains simple C++ examples of sorting algorithms and related utilities.

Files:

- `bubble_sort.cpp` — basic bubble sort example
- `insertion_sort.cpp` — insertion sort implementation
- `selection_sort.cpp` — selection sort implementation
- `counting_sort.cpp` — counting sort example
- `inbuilt_sort_comparator.cpp` — examples of `std::sort` and comparators
- `sorting_vector_pair.cpp` — sorting pairs (cartesian sort) example
