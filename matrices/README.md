# Matrices & 2D Arrays

Matrix-based patterns and utility functions.

Files:

- `2d_char_array.cpp` — example working with 2D char arrays
- `2d_prefix_sum.cpp` — compute 2D prefix sums
- `spiral_print.cpp` — spiral traversal of fixed-size 2D array
- `vector_spiral_print.cpp` — spiral traversal using vectors (dynamic)
- `reverse_wave_print.cpp` — column-wise reverse wave traversal
- `submatrix_sum.cpp` — submatrix sum queries using prefix sums
